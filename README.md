About the Project

Next Level Gaming & Esports Arena is a website we developed for our Work Integrated Learning (WIL) project.
The project is based on a gaming and esports business founded by Jason Naidoo in 2023 and located in Johannesburg, South Africa.
The idea behind the website is to give customers a place where they can learn more about the business, explore gaming experiences, view packages and calculate how much their booking could cost.
We also developed a mobile application for the same project. Both platforms have the same main features, but their layouts are designed to suit the devices they are used on.

What the Website Includes

- Home Page: Introduces the business and gives visitors an overview of what is available.
- About Us: Provides information about the business and its background.
- Gaming Experiences: Allows users to explore PC Gaming, Console Gaming and Esports.
- Calculate Fees: Allows users to select their gaming options and calculate an estimated cost, including discounts and 15% VAT.
- Memberships: Includes Bronze, Gold and Platinum membership options.
- Checkout: Allows users to continue with their selected membership.
- Tournaments & Community: Displays tournament information and allows users to enquire about upcoming events.
- Contact Us: Provides contact information, social media links and directions.

Technologies Used

- HTML5 – Used to structure the website.
- CSS3 – Used for the styling, layouts and responsive design.
- JavaScript – Used for calculations, form validation and interactive features.
- LocalStorage – Used to keep selected information available when moving between pages.
- Netlify – Used to host the website.

Design

We went with a dark gaming theme using crimson red, black and white as our main colours.
We wanted the website to feel like a proper gaming platform while keeping it easy to navigate.
The same branding is used in our mobile application so that both platforms feel connected.

Running the Project

If you want to run the website locally:

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file using your browser or the Live Server extension.
4. Explore the different pages and features.
